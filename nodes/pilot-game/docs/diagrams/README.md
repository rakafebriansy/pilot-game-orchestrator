# Diagrams Directory

Direktori ini (`docs/diagrams/`) berfungsi sebagai wadah penyimpanan untuk semua file diagram arsitektur, seperti:
- `flowchart.puml`
- `erd.puml`
- `state-diagram.puml`
- `use-case.puml`

Semua file diagram **WAJIB** ditulis menggunakan format PlantUML (`.puml`). Dilarang keras menaruh gambar statis (`.png`, `.jpg`) tanpa adanya kode sumber UML yang mendasarinya.

> *Catatan:* Direktori ini secara default menyertakan file `.gitkeep` untuk mempertahankan eksistensi foldernya di dalam Git meskipun belum ada file `.puml` yang dibuat. Anda dapat mengabaikan atau menghapus file `.gitkeep` tersebut ketika Anda sudah menempatkan file diagram pertama Anda di sini.
